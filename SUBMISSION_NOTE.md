# Key Decisions

The Manifest Prospecting Tool converts the public Manifest attendee list into a ranked venture-prospect database for Wittington Ventures. The implementation separates the workflow into data retrieval, cleaning, storage, deterministic screening, external enrichment, structured scoring, and review. This separation makes reruns predictable, reduces duplicate API usage, and keeps each stage inspectable.

The pipeline starts with the Manifest attendee page. `src/scrape.py` retrieves the attendee names. A local seed file is included so the app remains runnable if the live page changes, blocks scraping, or returns too little data. `src/clean.py` keeps the original company name for reviewer visibility and creates a normalized company key for deduplication. The normalized key is used for database identity, caching, and reruns, while the original name remains visible in the interface.

The app uses two main views. The Source list contains the cleaned and deduplicated attendee records after rule-based screening. The Verified prospects list contains companies that passed the initial screen, received external evidence enrichment through Tavily, and were scored with OpenAI. This separation avoids treating every cleaned attendee row as an investment prospect. The Manifest list includes startups, large companies, investors, consultants, associations, universities, retailers, logistics providers, and ambiguous records, so the product keeps raw coverage separate from scored prospects.

Cost control is handled before enrichment. The deterministic rules layer filters clear non-targets, including large incumbents without startup signals, investors, universities, associations, consultancies, brands, placeholder rows, and logistics service providers without software or platform evidence. Ambiguous companies are allowed into enrichment when the available record is insufficient for confident exclusion. Tavily retrieves public evidence for those companies, and OpenAI scores only the cached evidence rather than the raw attendee name alone.

The scoring rubric reflects Wittington’s stated focus areas: commerce, health, consumer, and climate, with a primary investment range around Series A/B and flexibility outside that range. Each company is evaluated across venture backability, Wittington sector fit, strategic edge, stage signal, traction signal, and evidence confidence. Caps limit the scores of non-startups and low-fit organizations, so prominent companies do not rank highly only because they are recognizable or adjacent to supply chain and logistics.

The Streamlit dashboard exposes the process through source preparation, API verification, sortable ranked prospects, model selection, batch-size controls, scoring weights, company detail pages, CSV exports, reset controls, and cost reporting. The cost summary tracks Tavily calls, OpenAI calls, input tokens, output tokens, estimated provider spend, total tracked API cost, and average spend per API-scored company. The resulting workflow retrieves source data with code, uses external APIs for evidence, applies model scoring to structured evidence, caches paid work, and presents the ranking with visible rationale and cost.
